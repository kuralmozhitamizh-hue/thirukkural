அறத்துப்பால் | அன்புடைமை

குறள்: 72

அன்பிலார் எல்லாம் தமக்குரியர் அன்புடையார்

என்பும் உரியர் பிறர்க்கு

பொதுவான பொருள்

அன்பு இல்லாதவர்கள் தங்களது பொருள்களைப் பிறருக்குத் தர மாட்டார்கள். அன்பு உடையவர்கள் தம் உடம்பையும் பிறருக்குத் தருவார்கள்.

மு. வரதராசனார் உரை

அன்பு இல்லாதவர் எல்லாப் பொருள்களும் தமக்கே உரிமை என்று கொண்டு வாழ்வர்; அன்பு உடையவர் தம் உடம்பும் பிறர்க்கு உரியது என்று வாழ்வர்.

மணக்குடவர் உரை

அன்பில்லாதார் எல்லாப் பொருளையும் தமக்கே உரியராக விரும்புவர்; அன்புடையார் தம்முடைய எலும்பையும் பிறர்க்கு உரிமையாக்குவர்.

சாலமன் பாப்பையா உரை

அன்பு இல்லாதவர் எல்லாமே எனக்குச் சொந்தம் என்பார்கள்; அன்பு உடையவரோ என் எலும்பும் பிறர்க்குப் பயன்படட்டும் என்பார்கள்.

சொல்லிலக்கணம் / சொற்பொருள்

அன்புடையார்: அன்பு உடையவர்கள்

சொல்லிலக்கணம் / சொற்பொருள்

என்பும்: உடம்பும் / எலும்பும்

1. வேற்றுமை அணி

இரு பொருள்களுக்கு இடையே உள்ள ஒற்றுமையைக் கூறி, பிறகு அவை ஒன்றுக்கொன்று மாறுபடும் வேற்றுமையைக் காட்டுவது வேற்றுமை அணியாகும்.

2. பகுதி / பகுபத உறுப்பிலக்கணம்

அன்பிலார்: அன்பு + இல் + ஆர்
இல் → எதிர்மறை இடைநிலை
ஆர் → பலர்பால் வினைமுற்று விகுதி

3. யாப்பு இலக்கணம் (அலகிடுதல்)

அன்-பி-லார் (நேர்-நிரை-நேர்) - புளிமாங்காய்
